## 6. 结果分析

### 6.1 预期结果范围

| 配置 | ICV占比 | 控制车辆数 | OCR | C_int | Final Score |
|------|---------|-----------|-----|-------|-------------|
| Baseline | 25% | 70-75辆 | 70-72% | 1.2-1.5 | 60-62 |
| **推荐** | 10% | 28-32辆 | 65-68% | 0.5-0.7 | **68-72** ✅ |
| 激进 | 5% | 14-18辆 | 58-62% | 0.3-0.4 | 56-60 |
| 极限 | 3% | 8-12辆 | 50-55% | 0.15-0.25 | 49-52 |

### 6.2 判断训练是否成功

**Stage 1成功标志**：
- ✅ Training Loss < 0.015
- ✅ Validation Loss < 0.020
- ✅ 数据收集的OCR在68-72%范围

**Stage 2成功标志**：
- ✅ Episode Reward持续上升
- ✅ OCR达到65%+（10%占比）
- ✅ 干预成本 < 0.7
- ✅ Final Score > 65

### 6.3 结果不理想的原因分析

**OCR太低（< 60%）**：
- 原因1：ICV占比设置太低（3-5%）
- 原因2：瓶颈区域定义不准确
- 原因3：启发式规则评分不合理
- 解决：增加ICV占比到10%，检查瓶颈区域配置

**干预成本太高（> 1.0）**：
- 原因1：控制的车辆太多
- 原因2：决策频率太高（decision_interval太小）
- 原因3：动作空间设计问题
- 解决：降低ICV占比，增加decision_interval

**最终得分不如Baseline**：
- 原因1：OCR下降太多（> 10%）
- 原因2：神经网络评分器训练不充分
- 原因3：PPO超参数需要调整
- 解决：重新训练Stage 1，调整学习率

## 8. 高级优化

### 8.1 超参数调优

**学习率调整**：
```yaml
# 如果训练不稳定（抖动大）
training:
  stage2:
    learning_rate: 0.00005  # 减小学习率

# 如果训练太慢（上升缓慢）
training:
  stage2:
    learning_rate: 0.0003   # 增大学习率
```

**PPO参数调整**：
```yaml
# v5_ppo_trainer.py中的参数
ppo:
  clip_range: 0.2      # 裁剪范围
  vf_coef: 0.5         # value function系数
  ent_coef: 0.01       # 熵正则化系数
  max_grad_norm: 0.5   # 梯度裁剪
```

### 8.2 自定义瓶颈区域

基于实际观察调整：

```yaml
heuristic_selector:
  # 方法1：单一区域
  bottleneck_s_min: 1400.0
  bottleneck_s_max: 2000.0
  
  # 方法2：多区域（使用competition_optimized.yaml）
  bottleneck_zones:
    - name: "j15_merge"
      s_min: 1200.0
      s_max: 1600.0
      priority: 1.5
    - name: "j17_merge"
      s_min: 1800.0
      s_max: 2200.0
      priority: 1.5
```

### 8.3 动态ICV数量

实现自适应控制：

```python
# src/env/competition_env.py
def adaptive_icv_ratio(self):
    """根据交通密度动态调整ICV占比"""
    density = self.get_traffic_density()
    
    if density > 0.8:
        return 0.15  # 拥堵时增加控制
    elif density > 0.5:
        return 0.10  # 正常流量
    else:
        return 0.05  # 畅通时减少控制
```

### 8.4 集成学习（Ensemble）

训练多个模型并集成：

```bash
# 训练3个不同seed的模型
for seed in 42 123 456; do

    --config configs/phase1_lite.yaml \
    --seed $seed \
    --device cuda
  
  python train_phase1_lite.py \
    --config configs/phase1_lite.yaml \
    --stage 2 \
    --seed $seed \
    --device cuda
done

# 集成评估
python scripts/ensemble_evaluate.py \
  --models checkpoints/seed_42 checkpoints/seed_123 checkpoints/seed_456 \
```
