# 🚀 训练快速参考卡

## ⚡ 一键启动

```bash
# 1. 激活环境
conda activate sumo
cd /home/wyyyz/TJ_transport_v4

# 2. Stage 1 (1.5-2小时 - 16并行环境加速)
python train_smart_selector.py --config configs/phase1_lite.yaml --device cuda

# 3. 更新配置（Stage 1完成后）
# 编辑 configs/phase1_lite.yaml
# 设置: neural_icv_scoring.checkpoint_path: checkpoints/phase1_lite/smart_selector_stage1.pth

# 4. Stage 2 (3-4小时)
python train_phase1_lite.py --config configs/phase1_lite.yaml --stage 2 --device cuda

# 5. 评估
python evaluate.py --config configs/phase1_lite.yaml \
  --checkpoint checkpoints/phase1_lite/best_model.pth --num-episodes 20
```

---

## ⚙️ 并行配置调整

**调整并行环境数**（根据CPU/内存配置）:
```yaml
# configs/phase1_lite.yaml
training:
  stage1:
    num_envs: 16  # 推荐8-16，根据机器配置调整
```

**性能对比**:
- 单环境: ~20小时数据收集
- 8环境: ~2.5小时 (8x加速)
- 16环境: ~1.5小时 (12-14x加速) ⭐推荐
- 32环境: ~1小时 (需要高配置机器)


## ❌ 常见错误

### CUDA Out of Memory
```bash
# 解决方案：使用CPU
python train_smart_selector.py --config configs/phase1_lite.yaml --device cpu
```

### SUMO连接失败
```bash
# 验证SUMO配置
ls -l 仿真环境_初赛_1.0/仿真环境-初赛/sumo_train.sumocfg

# 测试SUMO
sumo-gui -c 仿真环境_初赛_1.0/仿真环境-初赛/sumo_train.sumocfg
```

### Stage 2找不到checkpoint
```bash
# 检查路径
ls checkpoints/phase1_lite/smart_selector_stage1.pth

# 确认配置文件已更新
grep checkpoint_path configs/phase1_lite.yaml
```

## 📈 性能判断

### ✅ 训练成功
- Stage 1 Loss < 0.020
- Stage 2 Final Score > 65
- OCR > 65%
- 干预成本 < 0.7

### ❌ 需要调整
- Loss > 0.030 → 降低学习率
- OCR < 60% → 增加ICV占比到15%
- 干预成本 > 1.0 → 降低ICV占比到5%
