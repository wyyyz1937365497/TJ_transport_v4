## 🎯 设计动机

### 比赛核心挑战

根据比赛文档，初赛评分公式为：

$$
S_{total} = (W_{efficiency} \times S_{efficiency} + W_{stability} \times S_{stability}) \times e^{-k \cdot C_{int}}
$$

其中干预成本 $C_{int}$ 的计算为：

$$
C_{int} = C_{ICV} = \frac{1}{T_{total} \cdot N_{ICV}} \sum_{t=1}^{T_{total}} \sum_{i=1}^{N_{ICV}} (\alpha \cdot acmd_{i}(t) + \beta \cdot \delta lc_{i}(t))
$$

**关键洞察：**
1. **OCR（OD完成率）是主要目标** - 初赛权重70%
2. **干预成本直接影响最终得分** - 通过指数衰减惩罚
3. **车辆选择同样重要** - 选择最少、最关键的车辆控制

### 为什么需要智能车辆选择？

传统方法的问题：
- ❌ **固定控制25%车辆** - 干预成本高
- ❌ **随机或规则选择** - 可能选择不重要的车辆
- ❌ **无法动态调整** - 不同交通状态需要不同车辆

我们的方案：
- ✅ **动态选择5-10%关键车辆** - 降低干预成本
- ✅ **学习车辆影响力** - 选择对OCR影响最大的车辆
- ✅ **端到端优化** - 车辆选择和控制策略联合训练

## 💡 核心创新

### 1. 端到端车辆选择+控制框架

```
交通状态 → [GNN车辆影响力评估] → Top-K关键车辆 → [控制策略网络] → 动作 → OCR↑
           |___________________________|                              |
                      联合优化（反向传播）                            |
                                                                      |
                  奖励 = OCR增益 - 干预成本惩罚 <--------------------/
```

**关键点：**
- 车辆选择和控制策略**共享同一个损失函数**（OCR - 干预成本）
- 通过梯度反向传播，**同时优化两个模块**
- 实现**最少车辆、最大效果**的目标

### 2. 两阶段训练策略

#### Stage 1: 启发式引导（2-3小时）
**目标：** 让神经网络快速学会"哪些车重要"的基本模式

**方法：**
1. **启发式车辆选择器**：
   - 瓶颈区域车辆（优先级最高）
   - 低速车辆（容易造成拥堵）
   - 接近合流点的车辆
   - 即将换道的车辆

2. **启发式控制器**：
   - IDM（智能驾驶模型）
   - 保持安全车距
   - 最小化换道（降低成本）

3. **监督学习**：
   ```python
   损失 = BCE(神经网络评分, 启发式选择标签)
   ```

**优势：**
- 快速收敛（不需要从随机探索开始）
- 提供合理的初始策略
- 减少强化学习所需时间

#### Stage 2: 强化学习微调（3-4小时）
**目标：** 直接优化比赛得分

**方法：**
1. **环境交互**：使用神经网络选择车辆并控制
2. **奖励函数**：
   ```python
   奖励 = W_eff * ΔOCR - W_cost * 干预成本
   ```
3. **策略梯度**：优化神经网络参数

**优势：**
- 直接优化比赛目标
- 适应特定场景
- 发现启发式规则无法覆盖的策略

## 🔧 实现细节

### 启发式车辆选择器

```python
class HeuristicVehicleSelector:
    def select_vehicles(self, vehicle_states, icv_ids, top_k=30):
        scores = {}
        
        for veh_id in icv_ids:
            state = vehicle_states[veh_id]
            score = 0.0
            
            # 1. 瓶颈区域权重（最重要）
            if in_bottleneck_zone(state):
                score += 10.0
            
            # 2. 速度因子（速度越慢越重要）
            if state['speed'] < 0.5 * max_speed:
                score += 5.0 * (1.0 - state['speed'] / max_speed)
            
            # 3. 车道因子（内侧车道更重要）
            if state['lane_index'] <= 1:
                score += 3.0
            
            # 4. 与前车距离因子
            if state['lead_distance'] < 30.0:
                score += 4.0 * (1.0 - state['lead_distance'] / 30.0)
            
            scores[veh_id] = score
        
        # 选择Top-K
        return sorted(scores, key=scores.get, reverse=True)[:top_k]
```

**设计原则：**
- **瓶颈区域优先**：这是交通流最关键的位置
- **低速车辆重要**：低速车会引发连锁拥堵
- **前车距离小需控制**：避免追尾和停车
- **内侧车道优先**：影响更多后车

### 启发式控制器

```python
class HeuristicController:
    def compute_actions(self, vehicle_states, selected_ids):
        actions = {}
        
        for veh_id in selected_ids:
            state = vehicle_states[veh_id]
            
            # IDM加速度计算
            accel = self._compute_idm_accel(state)
            
            # 换道决策（极少换道以降低成本）
            lane_change = 0  # 默认保持
            
            # 只有在极端情况才换道
            if state['lead_distance'] < 10.0 and state['lane_index'] > 0:
                lane_change = -1  # 向左换道
            
            actions[veh_id] = [accel, lane_change]
        
        return actions
    
    def _compute_idm_accel(self, state):
        """智能驾驶模型（IDM）"""
        speed = state['speed']
        max_speed = state['max_speed']
        lead_dist = state['lead_distance']
        
        # 期望速度项
        speed_term = 1.0 - (speed / max_speed) ** 4
        
        # 安全距离项
        desired_spacing = min_spacing + speed * safe_time_gap
        spacing_term = (desired_spacing / max(lead_dist, 0.1)) ** 2
        
        # 组合
        accel = max_accel * (speed_term - spacing_term)
        
        return np.clip(accel, max_decel, max_accel)
```

**设计原则：**
- **IDM模型**：经典且有效的跟驰模型
- **最小化换道**：换道成本是加速度的5倍（β=5 vs α=1）
- **平滑控制**：避免剧烈加减速

### 神经网络架构

```python
class NeuralVehicleScorer(nn.Module):
    def forward(self, vehicle_features, edge_index, edge_attr):
        # 1. 特征嵌入
        x = self.embedding(vehicle_features)  # (N, 64)
        
        # 2. GNN层（学习车辆交互）
        for i in range(num_layers):
            x = self.gnn_layers[i](x, edge_index, edge_attr)
            x = self.layer_norms[i](x)
        
        # 3. 注意力评分（学习重要性）
        scores = self.attention_scorer(x)  # (N, 1)
        
        # 4. Sigmoid归一化
        scores = torch.sigmoid(self.score_head(scores))  # (N, 1)
        
        return scores
```

**关键特性：**
- **GNN学习交互**：捕捉车辆之间的影响关系
- **注意力机制**：自动识别关键车辆
- **轻量级设计**：~100K参数，快速推理

## 🏆 比赛优势

### 1. 降低干预成本（直接提升得分）

**传统方案：**
- 控制25%车辆 → $N_{ICV} = 150$
- 每步都控制 → $T_{total} = 36000$
- 频繁换道 → 高 $\beta \cdot \delta lc$

**我们的方案：**
- 控制5-10%车辆 → $N_{ICV} = 30-60$ ✅ **降低50-80%**
- 稀疏控制（每10步） → $T_{total} = 3600$ ✅ **降低90%**
- 最小化换道 → 低 $\beta \cdot \delta lc$ ✅ **降低70%**

**综合效果：**
$$
C_{int}^{new} \approx 0.1 \times C_{int}^{old}
$$

$$
P_{int}^{new} = e^{-k \cdot 0.1 \cdot C_{int}^{old}} \approx 0.9-0.95
$$

**vs** 原方案 $P_{int}^{old} \approx 0.3-0.5$

→ **得分提升 50-150%！**

### 2. 提升OCR（主要目标）

**智能选择关键车辆：**
- 瓶颈区域车辆 → 缓解拥堵源头
- 低速车辆 → 防止连锁反应
- 合流点车辆 → 优化汇流效率

**预期效果：**
- OCR提升 5-15%
- $S_{efficiency}$ 提升 10-30分

### 3. 训练效率

| 方案 | 训练时间 | GPU利用率 | 数据质量 |

| 随机探索 | 20-30小时 | 低 | 差 |
| 纯强化学习 | 12-18小时 | 中 | 中 |

## 📖 使用指南

### 快速开始

```bash

conda activate sumo
python train_smart_selector.py --config configs/phase1_lite.yaml --stage all

# 2. 分步训练
# Stage 1: 启发式引导（2-3小时）
python train_smart_selector.py --config configs/phase1_lite.yaml --stage 1

# Stage 2: 强化学习微调（3-4小时）
python train_smart_selector.py --config configs/phase1_lite.yaml --stage 2 \
    --checkpoint checkpoints/smart_selector_stage1.pth
```

### 配置文件

在 `configs/phase1_lite.yaml` 中添加：

```yaml
# 启发式选择器配置
heuristic_selector:
  bottleneck_s_min: 1000.0   # 瓶颈区域起点（米）
  bottleneck_s_max: 2000.0   # 瓶颈区域终点（米）
  max_accel: 2.0             # 最大加速度 (m/s²)
  max_decel: -4.0            # 最大减速度 (m/s²)
  safe_time_gap: 1.5         # 安全时间间隔 (秒)

# 训练配置
training:
  stage1:
    num_episodes: 100        # Stage 1数据收集episodes
    epochs: 20               # 训练轮数
    learning_rate: 0.001     # 学习率
  
  stage2:
    num_episodes: 50         # Stage 2强化学习episodes
    learning_rate: 0.0001    # 学习率（更小）
```

## 🚀 进一步优化方向

### 1. 多目标优化
- 同时优化OCR、稳定性、能耗
- 使用Pareto最优解

### 2. 自适应Top-K
- 根据交通状态动态调整控制车辆数
- 拥堵时控制更多，通畅时控制更少

### 3. 分层控制
- 战略层：决定控制区域
- 战术层：选择具体车辆
- 执行层：生成控制指令

- 集成投票选择车辆
