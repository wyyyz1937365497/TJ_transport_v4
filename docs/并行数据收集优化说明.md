## 📊 性能提升

| 并行环境数 | 数据收集时间 | 加速比 | 效率 |
|-----------|-------------|--------|------|
| 1 (基线) | ~20小时 | 1x | 100% |
| 8 | ~2.5小时 | 8x | 100% |
| **16 (推荐)** | **~1.5小时** | **12-14x** | **75-87%** |
| 32 | ~1小时 | 20x | 62% |

**说明**：
- 16个并行环境是性能和资源消耗的最佳平衡点
- 超过16个环境，效率下降明显（并行开销增加）
- 建议根据CPU核心数调整：核心数 ≥ 并行环境数

## 🎯 使用方法

### 1. 直接运行训练（使用默认16并行环境）

```bash
conda activate sumo
cd /home/wyyyz/TJ_transport_v4

# Stage 1训练（1.5-2小时）
python train_phase1_lite.py --config configs/phase1_lite.yaml --stage all --device cuda
```

### 2. 测试最优并行环境数

```bash
# 测试不同配置的性能
python test_parallel_collection.py \
  --config configs/phase1_lite.yaml \
  --num-envs 1 4 8 16 \
  --num-episodes 10

# 根据输出的"推荐配置"调整 configs/phase1_lite.yaml
```

### 3. 调整并行环境数

```yaml
# configs/phase1_lite.yaml
training:
  stage1:
    num_envs: 16  # 根据你的机器配置调整（8-16推荐）
```

## 🔧 机器配置建议

| CPU核心数 | 推荐并行数 | 内存需求 | 预计速度 |
|----------|-----------|---------|---------|
| < 8核 | 4 | 8GB | ~5小时 |
| 8-16核 | 8 | 16GB | ~2.5小时 |
| 16-32核 | **16** | 32GB | **~1.5小时** ⭐ |
| > 32核 | 32 | 64GB+ | ~1小时 |

**注意事项**：
- 每个SUMO实例占用约500MB-1GB内存
- 建议至少有 2×并行数 的CPU核心
- GPU仅用于神经网络训练，不影响并行环境
