## 🔄 训练流程

### 完整训练流程（两阶段）

```bash
# Stage 1: 启发式引导（~2-3小时）
# 目标：训练神经网络评分器模仿启发式选择
conda activate sumo
python train_smart_selector.py --config configs/phase1_lite.yaml --device cuda

# Stage 2: 强化学习微调（~3-4小时）
# 目标：使用现有的PPO训练器直接优化OCR
python train_phase1_lite.py --config configs/phase1_lite.yaml --stage 2 \
       --checkpoint checkpoints/smart_selector_stage1.pth
```

### 为什么这样设计？

**Stage 1（`train_smart_selector.py`）：**
- ✅ 独立的监督学习任务
- ✅ 不需要完整的强化学习框架
- ✅ 快速收敛，提供良好的初始策略
- ✅ 输出：训练好的神经网络评分器

**Stage 2（`train_phase1_lite.py`）：**
- ✅ 复用现有的完整PPO训练器（`v5_ppo_trainer.py`）
- ✅ 利用现有的OCR奖励计算（`ocr_rewards.py`）
- ✅ 直接优化比赛目标
- ✅ 避免重复实现训练逻辑

## 📊 配置文件调整

在`configs/phase1_lite.yaml`中添加：

```yaml
# 启发式选择器配置（用于Stage 1）
heuristic_selector:
  bottleneck_s_min: 1000.0   # 瓶颈区域起点（米）
  bottleneck_s_max: 2000.0   # 瓶颈区域终点（米）
  max_accel: 2.0             # 最大加速度 (m/s²)
  max_decel: -4.0            # 最大减速度 (m/s²)
  safe_time_gap: 1.5         # 安全时间间隔 (秒)

# Stage 1训练配置
training:
  stage1:
    num_episodes: 100        # 数据收集episodes
    epochs: 20               # 训练轮数
    learning_rate: 0.001     # 学习率

  # Stage 2使用现有的PPO配置（无需修改）
  stage2:
    num_episodes: 50
    learning_rate: 0.0001
    gamma: 0.99
    max_grad_norm: 1.0
```

### 场景2: 仅使用启发式选择器（Baseline）

```python
from train_smart_selector import HeuristicVehicleSelector, HeuristicController

# 创建选择器和控制器
selector = HeuristicVehicleSelector(config, frenet_system)
controller = HeuristicController(config)

# 在环境中使用
for step in range(num_steps):
    # 获取车辆状态
    vehicle_states = get_vehicle_states(env)
    icv_ids = get_icv_ids(env)
    
    # 选择关键车辆
    selected_ids = selector.select_vehicles(
        vehicle_states, icv_ids, top_k=30
    )
    
    # 生成控制动作
    actions = controller.compute_actions(
        vehicle_states, selected_ids
    )
    
    # 执行
    obs, reward, done, info = env.step(actions)
```

## 📝 注意事项

1. **OCR计算器参数：** 确保`num_icv_total`参数正确（场景中ICV总数）
2. **设备一致性：** 所有模块使用相同的device（'cuda'或'cpu'）
3. **Frenet坐标系：** 启发式选择器需要frenet_system（从环境获取）
4. **Top-K比例：** 建议使用5-10%（配置中的`top_k_ratio`）
