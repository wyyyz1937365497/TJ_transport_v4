## 一、设计哲学

### 1.1 核心原则

1. **分层解耦**：宏观流控与微观车控在架构与时间尺度上分离
2. **风险驱动**：安全不是约束底线，而是感知与决策的核心驱动力
3. **约束优化**：将成本视为数学优化的硬约束，而非简单奖励惩罚
4. **端到端学习**：ICV评分与策略生成联合训练，而非独立模块

### 1.2 契合赛题的灵魂

```
初赛（粒控流）：
├── 快智能体（车辆层）：决策周期0.1秒
├── 风险感知GNN：捕捉关键车辆蝴蝶效应
└── Top-K稀疏控制：只控制最关键的10-25%车辆

复赛（粒流协控）：
├── 慢智能体（设施层）：决策周期5-10秒
├── 异频协同：设施引导，车辆执行
└── 动态权重门控：自动平衡效率/稳定/成本
```

## 三、关键模块详解

### 3.1 感知层：风险敏感异构图GNN

#### 3.1.1 节点定义

```python
节点类型：
├── 车辆节点
│   ├── 特征：[s, d, vs, vd, speed, accel, lane, angle, in_bottleneck]
│   └── 维度：9维
│
└── 设施节点（复赛）
    ├── 信号灯：[相位, 剩余时间, 流量]
    └── VSL牌：[当前限速, 平均速度, 拥堵程度]
```

#### 3.1.2 边定义

```python
边类型：
├── 物理边（车道连接）
├── 感知边（前后车跟驰）
├── 交互边（并线、汇流）
└── 控制边（设施 → 车辆，复赛）

边特征：
├── 空间距离：dist = sqrt((Δs)² + (Δd)²)
├── 相对速度：Δv = v_i - v_j
├── TTC（碰撞时间）：TTC = dist / Δv（仅当逼近时）
└── THW（车头时距）：THW = dist / v_leader
```

#### 3.1.3 风险感知注意力

```python
class BiasedAttentionGNN:
    """
    风险感知的图注意力网络

    核心公式：
    α_ij = softmax(Q_i · K_j + β_risk)

    其中 β_risk = λ / (TTC_ij + ε)

    如果 TTC_ij < 3.0s:
        α_ij ← α_ij · 5.0  # 强制关注高风险
    """

    def forward(self, x, adj, risk_features):
        # risk_features: [B, N, N] TTC倒数

        # 基础注意力
        attention_scores = self.q_proj(x) @ self.k_proj(x).transpose(-2, -1)

        # 风险偏置
        risk_bias = self.lambda_weight * risk_features
        attention_scores = attention_scores + risk_bias

        # Softmax归一化
        attention_weights = F.softmax(attention_scores / np.sqrt(self.d_k), dim=-1)

        # 聚合
        messages = attention_weights @ self.v_proj(x)

        return messages
```

#### 3.1.4 层次化聚合

```python
class HierarchicalPooling:
    """
    层次化图池化

    三层聚合：
    1. 局部层：车-车交互（跟驰、并线）
    2. 路段层：同车道车辆聚合
    3. 全局层：所有路段聚合

    目的：
    - 降低计算复杂度 O(N²) → O(N)
    - 捕捉不同尺度的交通模式
    """

    def forward(self, embeddings):
        # embeddings: [B, N, D]

        # Level 1: 车辆级（原始嵌入）
        vehicle_features = embeddings  # [B, N, D]

        # Level 2: 车道级聚合
        lane_ids = vehicle_states[:, :, 6]  # [B, N]
        lane_features = []
        for lane in unique(lane_ids):
            mask = (lane_ids == lane)
            lane_feat = vehicle_features[mask].mean(dim=1)  # [B, D]
            lane_features.append(lane_feat)
        lane_features = torch.stack(lane_features)  # [B, L, D]

        # Level 3: 全局聚合
        global_features = vehicle_features.mean(dim=1)  # [B, D]

        return {
            'vehicle': vehicle_features,
            'lane': lane_features,
            'global': global_features
        }
```

- ❌ 不是：根据规则计算重要性
- ✅ 而是：让网络学习"什么样的车控制效果好"

**训练信号**：

```python
# 通过PPO的policy gradient自动学习
# 如果选择高importance车的动作 → 导致高奖励
# → 梯度回传 → 增加这辆车的importance
```

#### 3.2.2 网络结构

```python
class ImportancePredictor(nn.Module):
    """
    重要性预测头

    输入：GNN嵌入 [B, N, D]
    输出：重要性评分 [B, N, 1] ∈ [0, 1]

    特点：
    - 轻量级MLP（3层）
    - LayerNorm稳定训练
    - Dropout防止过拟合
    """

    def __init__(self, hidden_dim=64):
        self.mlp = nn.Sequential(
            nn.Linear(hidden_dim, 64),
            nn.LayerNorm(64),
            nn.ReLU(),
            nn.Dropout(0.1),

            nn.Linear(64, 32),
            nn.LayerNorm(32),
            nn.ReLU(),
            nn.Dropout(0.1),

            nn.Linear(32, 1)
        )

    def forward(self, embeddings):
        importance = self.mlp(embeddings)
        importance = torch.sigmoid(importance)  # [0, 1]
        return importance
```

### 3.3 稀疏门控机制（可微分Top-K）

#### 3.3.1 Gumbel-Softmax Trick

**问题**：Top-K选择是离散的，梯度无法回传

**解决**：Gumbel-Softmax + 直通估计器

```python
class SparseGate(nn.Module):
    """
    可微分的稀疏门控

    关键技术：
    1. Gumbel-Softmax：使离散选择可微分
    2. 直通估计器：前向hard，反向soft
    3. 动态K值：根据拥堵状态调整
    """

    def forward(self, importance, training=True):
        """
        Args:
            importance: [B, N, 1] 重要性评分
            training: 训练/推理模式

        Returns:
            selection_mask: [B, N, 1] 选择掩码
            k: 实际选择的车辆数
        """
        B, N, _ = importance.shape

        # 计算动态K值
        k = int(self.k_ratio * N)
        k = max(k, self.min_k)
        k = min(k, self.max_k)

        if training:
            # ========== 训练模式：Gumbel-Softmax ==========

            # 1. 添加Gumbel噪声
            gumbel_noise = -torch.log(-torch.log(
                torch.rand_like(importance) + 1e-10
            ) + 1e-10)
            logits = torch.log(importance + 1e-10) + gumbel_noise

            # 2. 温度缩放
            temperature = torch.clamp(self.temperature, 0.1, 5.0)
            scaled_logits = logits / temperature

            # 3. Softmax
            probs = F.softmax(scaled_logits, dim=1)

            # 4. 直通估计器
            _, top_k_indices = torch.topk(
                importance.squeeze(-1), k, dim=1
            )
            hard_mask = torch.zeros_like(probs)
            hard_mask.scatter_(1, top_k_indices.unsqueeze(-1), 1.0)

            # 前向：hard，反向：soft
            selection_mask = probs - probs.detach() + hard_mask

        else:
            # ========== 推理模式：Hard Top-K ==========
            _, top_k_indices = torch.topk(
                importance.squeeze(-1), k, dim=1
            )
            selection_mask = torch.zeros_like(importance)
            selection_mask.scatter_(
                1, top_k_indices.unsqueeze(-1), 1.0
            )

        return selection_mask, k
```

```python
class AdaptiveKSelector:
    """
    动态K值选择器

    根据全局拥堵状态调整控制车辆数

    逻辑：
    - 拥堵 < 30%: k_ratio = 0.05（最少控制）
    - 拥堵 < 60%: k_ratio = 0.10（适度控制）
    - 拥堵 < 80%: k_ratio = 0.15（较多控制）
    - 拥堵 ≥ 80%: k_ratio = 0.25（最多控制）
    """

    def compute_k_ratio(self, global_state):
        congestion = global_state['congestion_level']

        if congestion < 0.3:
            return 0.05  # 通畅：极少干预
        elif congestion < 0.6:
            return 0.10  # 轻度拥堵：适度干预
        elif congestion < 0.8:
            return 0.15  # 中度拥堵：较多干预
        else:
            return 0.25  # 严重拥堵：最多干预（官方上限）
```

```python
class FastAgent(nn.Module):
    """
    快速智能体（车辆层）

    决策周期：0.1秒（每步）
    动作空间：连续动作
        - 加速度：[-3, 2] m/s²
        - 换道概率：[0, 1]

    输入：
        - 局部观测（自身状态 + 周围车辆）
        - 全局态势（从GNN获取）
        - 设施指令（复赛，从慢智能体获取）

    策略：高斯策略（可学习std）
    """

    def __init__(self, hidden_dim=64):
        self.actor = nn.Sequential(
            nn.Linear(hidden_dim + 1 + 8, 128),  # 嵌入 + 选择 + 设施指令
            nn.LayerNorm(128),
            nn.ReLU(),
            nn.Dropout(0.1),

            nn.Linear(128, 64),
            nn.LayerNorm(64),
            nn.ReLU(),
            nn.Dropout(0.1),

            nn.Linear(64, 2)
        )

        # 可学习的log_std
        self.log_std = nn.Parameter(torch.zeros(2))

    def forward(self, embeddings, selection_mask, facility_cmds=None):
        # 拼接输入
        features = torch.cat([embeddings, selection_mask], dim=-1)
        if facility_cmds is not None:
            features = torch.cat([features, facility_cmds], dim=-1)

        # 策略输出
        action_mean = self.actor(features)

        # 加速度映射
        accel = action_mean[:, :, 0:1]
        accel = (accel + 1.0) / 2.0 * 5.0 - 3.0  # [-1,1] → [-3,2]

        # 换道映射
        lane_change = action_mean[:, :, 1:2]
        lane_change = (lane_change + 1.0) / 2.0  # [-1,1] → [0,1]
        lane_change = torch.clamp(lane_change, 0.0, 1.0)

        actions = torch.cat([accel, lane_change], dim=-1)

        return actions
```

```python
class SlowAgent(nn.Module):
    """
    慢速智能体（设施层）

    决策周期：5-10秒（事件触发 + 定时兜底）
    动作空间：混合动作
        - VSL限速：离散 {40, 60, 80} km/h
        - 信号灯相位：离散 {绿灯, 红灯}

    输入：
        - 全局流状态（从GNN获取）
        - 预测信息（从世界模型获取）

    策略：Categorical分布
    """

    def __init__(self, hidden_dim=64):
        # VSL头
        self.vsl_head = nn.Sequential(
            nn.Linear(hidden_dim, 32),
            nn.ReLU(),
            nn.Linear(32, 3)  # 3个限速值
        )

        # 信号灯头
        self.signal_head = nn.Sequential(
            nn.Linear(hidden_dim, 32),
            nn.ReLU(),
            nn.Linear(32, 2)  # 2个相位
        )

    def forward(self, global_features):
        # VSL动作
        vsl_logits = self.vsl_head(global_features)
        vsl_probs = F.softmax(vsl_logits, dim=-1)
        vsl_dist = Categorical(vsl_probs)

        # 信号灯动作
        signal_logits = self.signal_head(global_features)
        signal_probs = F.softmax(signal_logits, dim=-1)
        signal_dist = Categorical(signal_probs)

        return {
            'vsl': vsl_dist,
            'signal': signal_dist
        }
```

```python
class HeteroFreqController:
    """
    异频协同控制器

    协同逻辑：
    - 慢智能体输出作为快智能体的Context
    - 快智能体在设施引导下执行具体动作
    """

    def forward(self, obs, global_state):
        # 1. 慢智能体决策（每5-10秒）
        if self.should_update_facility():
            facility_output = self.slow_agent(global_state)
            self.facility_cmds = facility_output

        # 2. 快智能体决策（每0.1秒）
        fast_output = self.fast_agent(
            embeddings=obs['embeddings'],
            selection_mask=obs['selection'],
            facility_cmds=self.facility_cmds  # 从慢智能体获取
        )

        return {
            'vehicle_actions': fast_output,
            'facility_cmds': self.facility_cmds
        }

    def should_update_facility(self):
        """事件触发 + 定时兜底"""
        # 事件触发：检测到突发拥堵
        if self.detect_sudden_congestion():
            return True

        # 定时兜底：每10秒
        if self.step_count % 100 == 0:  # 10秒 = 100步
            return True

        return False
```

### 3.5 预测层：潜在世界模型

#### 3.5.1 RSSM架构

```python
class WorldModel(nn.Module):
    """
    潜在状态空间模型（RSSM）

    目的：
    - 在潜在空间预测未来状态
    - 为决策提供前瞻性信息
    - 降低计算复杂度

    双头设计：
    - z_flow: 流演化预测（用于效率评估）
    - z_risk: 风险演化预测（用于安全评估）
    """

    def __init__(self, latent_dim=64):
        # RNN编码器
        self.gru = nn.GRU(
            input_size=64,  # GNN嵌入维度
            hidden_size=latent_dim,
            num_layers=2
        )

        # 解码头
        self.flow_decoder = nn.Sequential(
            nn.Linear(latent_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 9)  # 预测车辆状态
        )

        self.risk_decoder = nn.Sequential(
            nn.Linear(latent_dim, 32),
            nn.ReLU(),
            nn.Linear(32, 1)  # 预测风险概率
        )

    def forward(self, embeddings, prev_hidden=None):
        """
        Args:
            embeddings: [B, N, D] 当前GNN嵌入
            prev_hidden: [num_layers, B, latent_dim] 前一时刻隐藏状态

        Returns:
            z_flow: [B, latent_dim] 流演化状态
            z_risk: [B, latent_dim] 风险演化状态
            hidden: 新的隐藏状态
        """
        # 全局池化
        global_features = embeddings.mean(dim=1)  # [B, D]

        # RNN前向传播
        if prev_hidden is None:
            z, hidden = self.gru(global_features.unsqueeze(0))
        else:
            z, hidden = self.gru(global_features.unsqueeze(0), prev_hidden)

        z = z.squeeze(0)  # [B, latent_dim]

        # 解耦输出
        z_flow = z  # [B, latent_dim]
        z_risk = z  # [B, latent_dim]（可以共享，也可以分开）

        return z_flow, z_risk, hidden
```

#### 3.5.2 预测辅助任务

```python
class PredictionAuxiliaryTasks:
    """
    预测辅助任务

    目的：
    - 帮助网络学习更好的表征
    - 提供额外的训练信号

    任务：
    1. 轨迹预测：预测未来5秒的车辆位置
    2. 风险预测：预测未来5秒是否发生急刹/冲突
    """

    def compute_prediction_loss(self, current_obs, future_obs):
        # 轨迹预测MSE
        pred_next_obs = self.world_model(current_obs)
        trajectory_loss = F.mse_loss(pred_next_obs, future_obs)

        # 风险预测分类
        risk_prob = self.risk_head(current_obs)
        risk_label = self.compute_risk_label(future_obs)
        risk_loss = F.binary_cross_entropy(
            risk_prob,
            risk_label.float()
        )

        return trajectory_loss + 0.5 * risk_loss
```

### 3.6 约束优化模块

#### 3.6.1 Cost Critic

```python
class ConstrainedCritic(nn.Module):
    """
    约束评论家

    核心思想：
    - 不仅预测Q(s,a)（价值）
    - 还预测C(s,a)（成本）

    目标：
    - 最大化 Q(s,a)
    - 约束 C(s,a) < threshold

    方法：拉格朗日松弛
    """

    def __init__(self, hidden_dim=64):
        # Value Critic
        self.value_net = nn.Sequential(
            nn.Linear(hidden_dim, 128),
            nn.ReLU(),
            nn.Linear(128, 1)
        )

        # Cost Critic
        self.cost_net = nn.Sequential(
            nn.Linear(hidden_dim, 128),
            nn.ReLU(),
            nn.Linear(128, 1)
        )

        # 拉格朗日乘子（可学习）
        self.lambda = nn.Parameter(torch.tensor(0.1))

    def forward(self, embeddings):
        value = self.value_net(embeddings)
        cost = self.cost_net(embeddings)
        return value, cost

    def compute_lagrangian_loss(self, rewards, costs, cost_threshold=0.5):
        """
        拉格朗日损失

        L = Q(s,a) - λ * (C(s,a) - threshold)

        如果 C(s,a) > threshold：
            λ 增大（更关注成本）
        否则：
            λ 减小（更关注奖励）
        """
        # 更新λ
        with torch.no_grad():
            cost_violation = (costs.mean() - cost_threshold).clamp(min=0)
            self.lambda.data += 0.01 * cost_violation
            self.lambda.data = self.lambda.data.clamp(0, 1.0)

        # 拉格朗日损失
        lagrangian_loss = -rewards.mean() + self.lambda * (costs.mean() - cost_threshold)

        return lagrangian_loss
```

#### 3.6.2 动态权重门控

```python
class DynamicWeightGate(nn.Module):
    """
    动态权重门控网络

    目的：
    - 根据当前状态动态调整奖励权重
    - 自动适应不同场景

    权重：
    - w_efficiency: 效率权重
    - w_stability: 稳定性权重
    - w_cost: 成本权重
    """

    def __init__(self):
        self.gate_net = nn.Sequential(
            nn.Linear(64, 32),  # 输入：全局状态嵌入
            nn.ReLU(),
            nn.Linear(32, 3)    # 输出：3个权重
        )

    def forward(self, global_state):
        """
        Args:
            global_state: [B, D] 全局状态嵌入

        Returns:
            weights: [B, 3] 归一化权重 [w_eff, w_stab, w_cost]
        """
        logits = self.gate_net(global_state)
        weights = F.softmax(logits, dim=-1)
        return weights

    def compute_weighted_reward(self, rewards, global_state):
        """
        计算加权的奖励

        Args:
            rewards: {
                'efficiency': float,
                'stability': float,
                'cost': float
            }
            global_state: [B, D]

        Returns:
            weighted_reward: float
        """
        weights = self.forward(global_state)  # [B, 3]

        weighted_reward = (
            weights[:, 0] * rewards['efficiency'] +
            weights[:, 1] * rewards['stability'] -
            weights[:, 2] * rewards['cost']
        )

        return weighted_reward.mean()
```

### 3.7 安全屏障层

```python
class SafetyShield:
    """
    双层安全屏障

    Level 1: 规则卫士（每步）
    - 物理限制检查
    - 加速度裁剪
    - 速度限制

    Level 2: 紧急避险（触发式）
    - TTC < 2.0s → 强制制动
    - 巨大负奖励
    """

    def __init__(self):
        self.ttc_threshold = 2.0
        self.max_decel = -4.5
        self.max_accel = 2.0

    def filter_action(self, action, vehicle_state):
        """
        过滤不安全的动作

        Args:
            action: [accel, lane_change]
            vehicle_state: {speed, position, ...}

        Returns:
            safe_action: 修正后的动作
            safety_reward: 安全奖励（惩罚）
        """
        accel, lane_change = action

        # Level 1: 规则检查
        accel = np.clip(accel, self.max_decel, self.max_accel)

        # Level 2: TTC检查
        ttc = self.compute_ttc(vehicle_state)

        if ttc < self.ttc_threshold:
            # 极度危险：强制制动
            accel = self.max_decel
            lane_change = 0.0
            safety_reward = -10.0  # 巨大负奖励
        else:
            safety_reward = 0.0

        safe_action = [accel, lane_change]
        return safe_action, safety_reward

    def compute_ttc(self, vehicle_state):
        """计算碰撞时间"""
        lead_dist = vehicle_state.get('leader_distance', 1000.0)
        relative_speed = vehicle_state.get('relative_speed', 0.1)

        if relative_speed <= 0.1:
            return float('inf')

        ttc = lead_dist / relative_speed
        return ttc
```

### 4.2 PPO更新（带约束）

```python
def update_constrained_policy(policy, optimizer, rollouts):
    """
    约束PPO更新

    关键点：
    1. 同时优化value和cost
    2. 拉格朗日松弛
    3. 动态权重调整
    """

    # 1. 计算GAE
    advantages = compute_gae(
        rollouts['rewards'],
        rollouts['values'],
        gamma=0.99,
        gae_lambda=0.95
    )

    cost_advantages = compute_gae(
        rollouts['costs'],
        rollouts['cost_values'],
        gamma=0.99,
        gae_lambda=0.95
    )

    # 2. 归一化
    advantages = (advantages - advantages.mean()) / (advantages.std() + 1e-8)
    cost_advantages = (cost_advantages - cost_advantages.mean()) / (
        cost_advantages.std() + 1e-8
    )

    # 3. 多次更新
    for epoch in range(10):
        # 重新计算
        outputs = policy(rollouts['obs'], rollouts['actions'])
        new_values = outputs['value']
        new_cost_values = outputs['cost_value']
        new_log_probs = outputs['log_prob']

        # PPO clip loss（奖励）
        ratio = torch.exp(new_log_probs - rollouts['log_prob'])
        surr1 = ratio * advantages
        surr2 = torch.clamp(ratio, 0.8, 1.2) * advantages
        policy_loss = -torch.min(surr1, surr2).mean()

        # Value loss
        value_loss = F.mse_loss(new_values, rollouts['returns'])

        # Cost PPO loss
        cost_ratio = torch.exp(new_log_probs - rollouts['log_prob'])
        cost_surr1 = cost_ratio * cost_advantages
        cost_surr2 = torch.clamp(cost_ratio, 0.8, 1.2) * cost_advantages
        cost_policy_loss = -torch.min(cost_surr1, cost_surr2).mean()

        # Cost value loss
        cost_value_loss = F.mse_loss(new_cost_values, rollouts['cost_returns'])

        # 熵正则化
        entropy = outputs['dist'].entropy().mean()

        # 拉格朗日损失
        lagrangian_loss = policy.lambda_param * (
            rollouts['costs'].mean() - 0.5
        )

        # 总loss
        loss = (
            policy_loss +
            0.5 * value_loss +
            0.5 * cost_policy_loss +
            0.5 * cost_value_loss -
            0.01 * entropy +
            lagrangian_loss
        )

        # 梯度更新
        optimizer.zero_grad()
        loss.backward()
        nn.utils.clip_grad_norm_(policy.parameters(), 0.5)
        optimizer.step()

        # 更新λ
        with torch.no_grad():
            cost_violation = (rollouts['costs'].mean() - 0.5).clamp(min=0)
            policy.lambda_param.data += 0.01 * cost_violation
            policy.lambda_param.data = policy.lambda_param.data.clamp(0, 1.0)
```
