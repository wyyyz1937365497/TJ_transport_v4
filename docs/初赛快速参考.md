# 初赛快速参考卡片

## 🚀 快速开始

```bash
# 一键训练（推荐）
./run_preliminary.sh

# 评估模型
python evaluate_preliminary.py
```

## 📋 核心配置

| 参数 | 值 | 说明 |
|-----|---|------|
| **智能车比例** | 25% | icv_ratio: 0.25 |
| **Top-K控制** | 8辆 | top_k: 8 |
| **训练步数** | 150万 | 5个级别总和 |
| **评分重点** | 效率 | speed_weight: 2.0 |

## 🎯 训练阶段

```
Phase 1 (2-3小时)
  ├─ WorldModel预训练
  └─ GNN + RSSM特征学习

Phase 2 (8-12小时)
  ├─ Level 1: 10辆, 800流量
  ├─ Level 2: 15辆, 1200流量
  ├─ Level 3: 20辆, 1800流量
  ├─ Level 4: 32辆, 2400流量
  └─ Level 5: 32辆, 2000流量 ⭐
```

## 📊 目标性能

- ⭐ **平均速度**: > 12 m/s（优秀: > 15 m/s）
- ⭐ **吞吐量**: > 0.8 veh/step
- ⚠️ **干预率**: < 30%

## 🔧 常用命令

### 训练
```bash
# 完整训练
./run_preliminary.sh

# 跳过Phase 1
./run_preliminary.sh --skip-phase1

# 从Level 3开始
./run_preliminary.sh --start-level 3

# 分步训练
python train_preliminary.py --config configs/competition_preliminary.yaml
```

### 评估
```bash
# 基础评估（20 episodes）
python evaluate_preliminary.py

# 完整评估（50 episodes）
python evaluate_preliminary.py --episodes 50 --verbose

# 评估指定模型
python evaluate_preliminary.py \
    --checkpoint checkpoints/competition/preliminary/level5/custom_ppo.zip
```

### 监控
```bash
# 查看日志
tail -f logs/preliminary/level5/*.log

# TensorBoard
tensorboard --logdir logs/preliminary

# 系统检查
./check_training_setup.sh
```

## 🛠️ 快速修复

### 问题：训练太慢
```yaml
# 减少训练步数
curriculum_levels:
  - level: 5
    total_timesteps: 500000  # 996000 → 500k
```

### 问题：干预率过高（> 50%）
```yaml
# 增加成本惩罚
environment:
  rewards:
    intervention_cost_weight: 1.0  # 0.5 → 1.0

# 减少Top-K
model:
  controller:
    top_k: 5  # 8 → 5
```

### 问题：平均速度过低（< 10 m/s）
```yaml
# 增加效率奖励
environment:
  rewards:
    speed_weight: 3.0      # 2.0 → 3.0
    efficiency_weight: 4.0  # 3.0 → 4.0
```

### 问题：显存不足
```yaml
training:
  phase2:
    batch_size: 128  # 256 → 128
```

### 问题：训练不稳定
```yaml
training:
  phase2:
    learning_rate: 1e-4  # 3e-4 → 1e-4
    batch_size: 512      # 256 → 512
```
